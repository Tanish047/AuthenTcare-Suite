## 💡 **How It Works**

### **Document Upload Process**
1. User drags file into Document Hub
2. File content is extracted and chunked
3. Chunks stored in memory with metadata
4. Document appears in document list
5. Ready for AI queries immediately

### **AI Query Process**
1. User asks question in AI Chat
2. Service searches document chunks for relevant content
3. Relevant chunks sent to AI as context
4. AI generates answer based on documents + knowledge
5. Response shows document sources

### **Example Interaction**
```
User uploads: "FDA_510k_Guidance.pdf"
User asks: "What are the 510k requirements?"

AI Response: "Based on your uploaded FDA guidance:
- Device description and intended use
- Substantial equivalence comparison
- Performance data
- Labeling requirements
- Risk analysis

Sources: FDA_510k_Guidance.pdf (95% relevant)"
```
